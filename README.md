# O Altar no Mundo — Landing Page

Página de vendas do e-book devocional **O Altar no Mundo** (30 dias com as santas), de Pietra Gratia / Afinidade com Deus.

Design feminino, leve e acolhedor (creme, rosa e dourado), otimizado para mobile.

**Rascunho:** itens tracejados (preço, foto da autora, depoimentos) pendentes de definição.
